# getreviewsdream99

This repository contains a static website for `demystifygetreviewssuperb99.com`.

## What the site does

- Lets users post dreams and share them publicly
- Allows commenters to leave reviews and comments on each dream
- Requires a manual $5 BTC or ETH payment before publishing the second dream
- Uses live exchange rates from CoinGecko to calculate the BTC and ETH amount for $5

## Files

- `index.html` — website markup
- `styles.css` — page styling
- `script.js` — client-side logic for posting dreams, comments, and payment handling

## Deploy to Vercel

1. Push this repository to GitHub.
2. Connect it to Vercel and configure a static site deployment.
3. Ensure the root directory contains `index.html`.

The site is designed to work as a static deployment without server-side code.
